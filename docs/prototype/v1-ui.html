Prototype #6

What to try, and what to watch

This is a throwaway clickable prototype for issue #6. The library is 41 games of sample data; cover art loads from the Steam CDN at runtime.

The 60-second job

  1. Select two or three games in the library, then choose New from selection.
  2. Name the collection, then add a Tag, a Playtime rule, and a Steam Collection rule.
  3. Open the game list rule and choose Use selection.
  4. Watch the match count update, then save. Use the timer in the bar below.

What to watch

  • Do the prefix-first rows make the global AND / OR / NOT grouping understandable?
  • Is the game list obvious enough, or does it hide behind the value control?
  • Does the live result pane make the editor feel safe enough to experiment?
  • What feels slow or confusing? The notes file records the friction I hit while building it.

States in the switcher

Normal, first run, loading, empty library, metadata refresh, and ownership error. The last two keep the library usable. Each state is also addressable with ?scenario=error or ?scenario=refreshing.

Keyboard: / search, Esc closes panels, Ctrl+S saves a collection.
